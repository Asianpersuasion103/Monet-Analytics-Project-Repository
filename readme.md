# Intern Code Repository

This repository is used by interns to push their assigned work.

## Workflow

Each intern should create their own branch using their name:

```bash
git checkout -b <your-name>
```

Example:

```bash
git checkout -b john-doe
```

Push your branch:

```bash
git push -u origin john-doe
```

## Guidelines

* Do not push directly to `main`.
* Keep your work on your assigned branch.
* Use meaningful commit messages.
* Keep the code clean and organized.
* Do not commit passwords, API keys, or other secrets.
* Create a Pull Request when your work is ready for review.

## Branch Example

```text
main
 ├── john-doe
 ├── jane-doe
 └── alex-doe
```
